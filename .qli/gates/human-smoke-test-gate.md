# Human Smoke Test Gate

Human smoke testing is mandatory for implemented user-visible behavior.

## Required smoke record

- Entry URL/route/command:
- User/role/context:
- Test data used:
- Steps:
- Expected result:
- Actual result:
- Screens/states checked:
- Access denied/error path checked:
- Pass/fail/blocker:

## Rule

A product feature with UI is not accepted solely because unit tests pass. The user or reviewer must have a realistic path to inspect the feature.

Placeholders are allowed only when labeled and when the placeholder still supports navigation, layout, review, and future implementation without misleading the reviewer.
