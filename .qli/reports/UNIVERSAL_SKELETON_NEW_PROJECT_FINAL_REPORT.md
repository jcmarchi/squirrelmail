## Removed from active baseline

- Runtime Kickstart scripts.
- Kickstart question/manual automation layer.
- Existing-project adoption workflow files.
- Existing-project intake/risk/snapshot project-state files.
- Existing-project adoption skills and prompts.
- Historical patch/release reports.
- Legacy compatibility folder.
- Buildline validation scenario folder.

## Retained

- QLi Buildline foundations.
- Binding layer for project-specific applicability.
- Project state placeholders for new project customization.
- Foundation Spine, gates, evidence, workflows, and optional skills.
- Doctor scripts for structural verification.
- AI Co-Architect handoff guidance.

## Intended use

The AI Co-Architect customizes this skeleton after product brainstorming and architecture are complete. The coding agent should receive the already-customized project repo and should not be asked to infer product architecture from generic placeholders.
