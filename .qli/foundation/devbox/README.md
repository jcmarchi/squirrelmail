# DevBox Foundation — Current

This is the live server-side DevBox Foundation library for managed-project onboarding.

Canonical server path:

`/srv/dev/foundation/devbox/current/`

Project-local destination for DevBox-managed projects:

`.qli/foundation/devbox/`

This foundation governs DevBox runtime/onboarding concerns only: project placement, port block assignment, runtime overrides, route registration, Caddy exposure, smoke checks, and AI-agent-safe onboarding.

It does not override project-native product doctrine, architecture, roadmap, stack decisions, API contracts, or data models.
