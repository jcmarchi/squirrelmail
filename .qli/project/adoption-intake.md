## Application Type

Legacy PHP webmail application. Self-hosted, multi-user, browser-based email client. Communicates with external IMAP and SMTP servers. No database required for core operation (file-based preferences and address books).

## Architecture Summary

### Entry Points
- `index.php` (root) — redirects to `src/login.php` if config exists
- `src/login.php` — authentication form, session initialization
- `src/redirect.php` — post-login redirect, session establishment, IMAP login
- `src/webmail.php` — main mailbox interface (frameset-based)
- `src/compose.php` — message composition
- `src/configtest.php` — configuration diagnostic tool

### Central Initialization
- `include/init.php` — loaded by every src/ page. Sets up SM_PATH, seeds RNG, cleans register_globals, defines base URI, loads constants, starts session, loads config files in order: `config_default.php` → `config.php` → `config_local.php`

### Configuration Model
- `config/config_default.php` — all default settings, ~700 lines, heavily documented
- `config/config.php` — site-specific overrides (generated by `config/conf.pl`)
- `config/config_local.php` — optional local overrides
- DevBox: `docker/devbox.config.php` mounted as `config/config.php`

### Authentication/Session Flow
1. User submits credentials via `src/login.php`
2. `src/redirect.php` encrypts password with one-time pad, stores in cookie
3. `sqimap_login()` in `functions/imap_general.php` connects to IMAP server
4. On success, session regenerated, `user_is_logged_in` flag set
5. `sqauth_is_logged_in()` in `functions/auth.php` checks session + optional referrer
6. Password stored encrypted in session cookie (one-time pad), never in plain text on disk

### IMAP Integration
- Custom IMAP client implementation in `functions/imap_general.php`, `functions/imap_messages.php`, `functions/imap_mailbox.php`
- Raw socket communication (fsockopen), not PHP IMAP extension
- Supports: LOGIN, PLAIN, CRAM-MD5, DIGEST-MD5, SCRAM-* auth
- Supports: TLS (imaps and STARTTLS)
- NAMESPACE support
- Server type presets: bincimap, courier, cyrus, dovecot, exchange, hmailserver, macosx, mercury32, uw, other
- DevBox: Dovecot 2.3.21 on `imap:143`, plain auth, no TLS

### SMTP/Sendmail Integration
- Two modes: direct SMTP or local sendmail binary
- SMTP: `functions/compose.php` delivers via `$smtpServerAddress:$smtpPort`
- Supports: LOGIN, PLAIN, CRAM-MD5, DIGEST-MD5, SCRAM-* SMTP AUTH
- Supports: TLS (ssmtp and STARTTLS)
- DevBox: Mailpit on `smtp:1025`, no auth, capture mode

### MIME/Message Parsing
- `class/mime.class.php` — MIME message parsing (~3100 lines)
- `functions/mime.php` — MIME helper functions
- `class/mime/` — MIME sub-classes (header parsing, decoding)
- Handles: multipart, attachments, inline images, HTML, character set decoding
- Message IDs: Version 5 UUID based on 64 cryptographically secure random bytes

### Preferences/User Data Storage
- File-based: `$data_dir/<hashed_username>/<pref_file>`
- Optional database backends via DSN (`$prefs_dsn`)
- Hash directory levels (0-4) for scalability
- `functions/prefs.php` — file-based storage functions
- Default preferences in `config/default_pref`
- DevBox: `/var/local/squirrelmail/data/` (Docker volume)

### Address Book
- `functions/addressbook.php` — address book abstraction
- Backends: local_file, database, LDAP
- File-based: `$data_dir/<username>.abook`
- Global shared address book supported
- DevBox: local_file backend (default)

### Plugin Model
- `functions/plugin.php` — hook system
- Plugins register via `config/plugin_hooks.php` (generated by conf.pl)
- `do_hook($name, &$args)` — executes all registered plugins for a hook
- 18 bundled plugins: administrator, bug_report, calendar, change_password, demo, filters, fortune, info, listcommands, mail_fetch, message_details, newmail, preview_pane, sent_subfolders, spamcop, squirrelspell, test, translate
- Each plugin has `setup.php` for initialization
- Global hook registry: `$squirrelmail_plugin_hooks`

### Template/Theme Model
- `class/template/Template.class.php` — abstract template class
- Template sets: configurable, default set provided
- Theme system: CSS themes in `themes/` directory, color arrays in PHP
- 11+ bundled themes (alien_glow, autumn, black_bean_burrito, etc.)
- Output: HTML 4.01 Transitional, frameset-based layout

### Localization/i18n
- `functions/i18n.php` — translation infrastructure
- `class/l10n.class.php` — localization class
- `functions/gettext.php`, `functions/ngettext.php` — gettext wrappers
- Translations in `locale/` and `help/<lang>/`
- Language detected from browser or user preference cookie
- Right-to-left CSS support (`css/rtl.css`)

### Security-Sensitive Surfaces
- Password handling: one-time pad encryption, cookie-stored, never plain on disk
- Session: PHP sessions, HttpOnly cookies, SameSite=Strict
- Session fixation: `session_regenerate_id()` after login
- XSS: CSP frame-ancestors header, htmlspecialchars encoding
- Referrer checking: optional `$check_referrer` for anti-phishing
- register_globals: cleaned in init.php if enabled
- Configtest: remote access blocked by default (`$allow_remote_configtest=false`)
- File permissions: data_dir outside web root, attachment_dir with 0733

### Runtime Assumptions
- PHP 7.0+ (tested on 8.3)
- No PHP IMAP extension required (custom implementation)
- No database required for core (file-based preferences)
- Write access to data_dir and attachment_dir
- IMAP server accessible from web server
- SMTP server or sendmail binary accessible
- Apache with mod_rewrite not required (direct .php access)
- Session cookies enabled

### DevBox Baseline
- PHP 8.3 Apache on 127.0.0.1:20110
- Dovecot IMAP on internal network
- Mailpit SMTP capture on internal network
- Data/attach dirs as Docker volumes
- Config via docker/devbox.config.php
- Test accounts: testuser/testpass, devbox/devbox
