# UI Demo Checklist

> **QLi v2 path notice:** Canonical Foundation source files live under `.qli/`. Any older legacy docs/specs path in this file is a legacy reference and should be resolved through `.qli/foundation-map.yml`. Do not create duplicate `.qli` Foundation files unless explicitly requested.


**Intended location:** `/docs/ui-demo-checklist.md`  
**Purpose:** Verify that the UI foundation demo/reference page is usable as a regression and reuse control surface.

## Required Demo Coverage

- [ ] Design tokens are visible or documented.
- [ ] Light theme shown.
- [ ] Dark theme shown when in scope.
- [ ] High-contrast theme shown when in scope.
- [ ] Buttons and action components shown in all variants and states.
- [ ] Form controls shown with labels, help text, errors, disabled, readonly, and loading states.
- [ ] Cards, badges, avatars, empty states, skeletons, progress, and spinners shown.
- [ ] Header, sidebars, navigation tree, tabs, breadcrumbs, pagination, and command palette shown when implemented.
- [ ] Dropdowns, context menus, tooltips, popovers, modals, drawers, and toasts shown when implemented.
- [ ] Data table shown with sorting, filtering, pagination, loading, empty, error, selected, and server-side mode if implemented.
- [ ] Responsive behavior checked at xs, sm, md, and lg widths.
- [ ] Keyboard navigation checked.
- [ ] Focus visibility checked.
- [ ] Overlay clipping checked.
- [ ] RTL checked when in scope.
- [ ] Component inventory matches demo contents.
