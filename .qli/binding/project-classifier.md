# Project Classifier

## Purpose

Classify a new project so QLi Buildline can determine which Foundations apply and what the upfront Spine must include.

This Universal Skeleton is for new projects only. Do not use this classifier for existing-project adoption.

## Classification Inputs

The AI Co-Architect should use the completed product documentation and architecture material to classify:

- product type
- user surfaces
- API/interface surfaces
- data persistence needs
- identity/authentication model
- ACL and tenancy model
- deployment target
- runtime model
- security/data sensitivity
- observability needs
- DevBox usage
- first vertical slice

Do not ask the project owner to retype values that already exist in the product documentation.
