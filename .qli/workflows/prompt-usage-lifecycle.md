# Prompt Usage Lifecycle

## Purpose

Keep AI coding-agent prompts short, scoped, and tied to Buildline state.

## Lifecycle

1. Use Compact Prompt 00 if context is missing or stale.
2. Use Compact Prompt 01 if project binding/applicability is incomplete.
3. Use Compact Prompt 02 to build the Foundation Spine.
4. Use Compact Prompt 03 for approved vertical product slices.
5. Use Compact Prompt 04 for gate review.
6. Use Compact Prompt 05 for hardening review.
7. Use Compact Prompt 06 for doctor/audit checks.
8. Use Compact Prompt 07 only when agent instruction files need safe integration.

Do not use a product-code prompt for a read-only review.
