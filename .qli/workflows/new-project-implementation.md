# New Project Implementation Workflow

## Purpose

Use this workflow after the AI Co-Architect has customized the Universal Skeleton into a project-specific Buildline-ready repository package.

## Sequence

1. Confirm project-specific root docs and `/docs/` exist.
2. Confirm `.qli/project/` files are completed or intentionally marked blocked.
3. Confirm the first current slice is defined.
4. Build the applicable Foundation Spine.
5. Implement the first vertical product slice.
6. Run focused checks and human smoke review.
7. Update evidence, status, and deferrals.

## Rule

Do not ask the coding agent to infer the product from placeholders. If placeholders remain in project-critical files, stop and return to AI Co-Architect skeleton customization.
